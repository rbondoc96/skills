# Accessibility

Own keyboard operation, focus, semantic structure, accessible names, assistive technology, contrast, and motion. UI/UX owns broader interaction clarity.

## Investigate

- Trace keyboard entry, operation, and exit from controls/dialogs, including focus restoration and visible focus.
- Check native semantics, names, descriptions, errors, announcements, and dynamic updates against the rendered accessibility structure when available.
- Check contrast, zoom/reflow, target interaction, and reduced-motion behavior where relevant and observable.

## Evidence bar

Name the affected user/task, interaction sequence, and inaccessible outcome. Separate source-inspected risks, automated findings, and manually exercised behavior. State missing browser, assistive-technology, or visual evidence. Verify any precise standards-compliance claim against the applicable standard; avoid blanket compliance verdicts from limited inspection.
