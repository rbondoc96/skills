# Language and Structure

BAD

> ❌ Users are currently experiencing an inability to successfully complete the profile update workflow in circumstances where their display name contains punctuation characters.

This is formal, indirect, and harder to scan than necessary.

GOOD

> ✅ Profiles fail to save when the display name contains punctuation. People should be able to use their real names.

This uses familiar words, short sentences, and states the problem directly.

BAD

> ❌ The purpose of this issue is to make changes to the existing retry behavior so that users are no longer required to manually refresh the application when their connection has been interrupted.

This takes a long route to the point.

GOOD

> ✅ Live updates stop after a connection drop. Reconnect automatically so people do not need to refresh the page.

This separates the problem and desired outcome into two short sentences.
